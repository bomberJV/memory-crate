Inside an inference.

Before a language model can write a single word, it has to read what you gave it.

On your device

Run the departure notice through the same model in your browser. The first run downloads approximately 137 MB of model weights plus the runtime.

Inputs, measurements and limitations

The browser uses 8-bit ONNX weights and a single WebAssembly thread. It can generate different tokens from the full-precision recording. Browser timings run from generation start to each emitted token. Loading time is separate. GPU memory and power are unmeasured.
